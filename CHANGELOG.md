# Changelog

## 1.0.0 — first release

The local‑first receipt keeper that never lets a return window or warranty slip.

**Capture & organize**
- Camera capture with AI extraction (merchant, total, date, category, line items) + manual review
- Searchable vault with photo thumbnails, filters (returns open, under warranty, reimbursable, this month), edit & delete
- Custom categories on top of the built‑in set

**Deadlines**
- Auto‑computed return‑by and warranty‑expiry countdowns
- Local reminders with a configurable lead time (1 / 3 / 7 days) + a "send test" check
- Claim Helper drafts a return/warranty email; mark claims filed → resolved

**Money**
- Spending by month & category, budgets (monthly goal + per‑category limits)
- Savings — under‑budget savings, savings goals you contribute toward, and money owed back
- Insights (trends, top merchants, recurring/subscription detection)
- Reimbursable flagging + CSV export

**Privacy & sync**
- App Lock — Face ID / Touch ID / passcode to open the vault
- Dark mode (Light / Dark / System)
- Optional cloud sync via a private sync code, or an email account for cross‑device sync
- Email import — forward an e‑receipt to a private address

_First App Store submission (build 1)._
